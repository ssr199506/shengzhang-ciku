## 一、评估体系（先定义"最优"，再谈搜索）

### 1.1 评估集（已内嵌/可加载）

| 集合 | 来源 | 内容 | 期望 |
|---|---|---|---|
| `KEEP` | tune_params 金标准 | 37 个应保留词（吞噬星空/一人之下/世界/修仙…） | 全部保留 |
| `FILT` | tune_params 金标准 | 25 个应滤除词（我只/联盟之/之巅…） | 全部滤除 |
| `T000` | 错题集 000 层 | 15 个干净真词（庆余年/康熙/首富/围棋/谍战…） | 尽量召回 |
| `FRAG` | 错题集/实测 | 18 个碎片（我只/聊天/联盟之/罗之/我的/这个…） | 尽量滤除 |
| `RAW` | scan 候选 | 7150 个候选词（带 count） | 基数 |

### 1.2 指标

```
keep_rate  = |kept ∩ KEEP| / |KEEP|        （应保留的保留率）
filt_rate  = |kept ∩ FILT| 的补 / |FILT|   （应滤除的滤除率）
recall_000 = |kept ∩ T000| / |T000|        （000 真词召回）
frag_rate  = |kept ∩ FRAG| / |FRAG|        （碎片残留率，越低越好）
collateral = |(RAW−kept) 中 count≥5 且 ∉FILT∪FRAG|   （疑似误伤数，越低越好）
```

### 1.3 综合损失函数（深度学习思路的核心）

定义 **score**（越大越好）与 **loss L = 1 − score**：

```
score = w1·keep_rate + w2·filt_rate + w3·recall_000 − w4·frag_rate − w5·collateral_norm
collateral_norm = collateral / |{RAW 中 count≥5 的词}|
```

**三套权重**（对应不同产品偏好，最终一起报告）：

| 方案 | w1 keep | w2 filt | w3 recall_000 | w4 frag | w5 collateral |
|---|---|---|---|---|---|
| A 保守（保真） | 0.35 | 0.35 | 0.10 | 0.10 | 0.10 |
| B 均衡 | 0.25 | 0.25 | 0.25 | 0.15 | 0.10 |
| C 召回（救真词） | 0.15 | 0.15 | 0.45 | 0.15 | 0.10 |

> 坐标下降对 loss 求极小值；每套权重各跑一轮，避免"权重拍脑袋定死"。

## 二、参数空间（含极端范围）

### 2.1 连续参数（可做一阶差分）

| 参数 | 面板键 | 当前推荐 | **扫描/极端范围** | 语义边界 |
|---|---|---|---|---|
| 复合熵阈值 | min_ent | 0.5 | **0.0 ~ 2.0**（档 0.05） | 0=关；>1.5 基本全滤 |
| 合并触发比 | ent_merge_ratio | 0.25 | **0.0 ~ 0.9**（档 0.05） | 0=关（no_merge 等价） |
| 凝固度阈值 | min_cohesion | 1.5 | **0.0 ~ 10.0**（档 0.1/0.5） | 0=关；>5 高凝固词才留 |
| 词本身偏序阈值 | min_indep | 0.05 | **0.0 ~ 1.0**（档 0.01/0.05） | 0=关；1.0=只留完全不包裹 |
| SPE 救援阈值 | spe_rescue | 0.0 | **0.0 ~ 2.0**（档 0.05） | 0=关；>1.5 只救焊死位多样词 |
| RSR 救援阈值 | rsr_rescue | 0.0 | **0.0 ~ 50**（档 1/5） | 0=关；与 spe 取 AND |
| 前后集中度门 | bind_thresh | 1.0 | **0.5 ~ 1.0**（档 0.05） | <1.0 才激活 |

### 2.2 离散/枚举参数

> 离散参数与连续参数同框架处理：**动一档看 Δscore**（如 rsr_mode mean→max、min_super_cnt 1→2→4→8、
> cohesion_max_len 4→6→8→12），Δscore 即其"差分梯度"，无需枚举全交叉组合。

| 参数 | 面板键 | 取值 | 处理方式 |
|---|---|---|---|
| RSR 聚合 | rsr_mode | mean / max | 差分：mean→max 看 Δscore |
| 超词门槛 | min_super_cnt | 1 / 2 / 4 / 8 | 差分：逐档看 Δscore |
| 标点感知熵 | no_punct_ent | false / true | 差分：关→开看 Δscore |
| 合并模式 | no_merge | false / true | 差分：关→开看 Δscore |
| 凝固度最大长 | cohesion_max_len | 4 / 6 / 8 / 12 | 差分：逐档看 Δscore |

> ⚠️ 成本提示：no_punct_ent / no_merge / cohesion_max_len 变动会触发**重 scan**（0.25s/次）；
> rsr_mode / min_super_cnt 只重算 cal_spe_rsr（≈0.02s）；其余纯阈值参数 gate 重跑（≈0）。

## 三、方法学（四层递进）

### 3.1 控制变量法（单参数敏感性，粗跑 + 精跑）

- **基准点** θ₀ = 当前推荐（me0.5, mr0.25, coh1.5, indep0.05, spe0, rsr0, bind1.0）。
- **规则**：每次只动一个参数，其余锁死在 θ₀；该参数按 2.1/2.2 档位全扫。
- **两阶段（coarse-to-fine）**：
  - 粗跑：大步长（细档位数的 1/4~1/5）全空间扫，定位单调段 / 拐点 / 平台交界 = **可疑区间**；
  - 精跑：只对可疑区间细化（区间 = 粗峰值 ± 1~2 个粗步长），锁定精确阈值。
- **输出**：每参数一张表（参数值 → score/keep/filt/000/碎片/误伤），定位：
  - 单调区间、平台期、拐点；
  - 谁对 score 影响最大（**敏感性排序** = 后续坐标下降动哪维的依据）。
- 实现：`调参产物/sens_single.py`（粗跑一次 scan_once 复用；仅 mr 档需重 scan，见 2.2 成本提示）。

### 3.2 极端参数边界测试

- 对每个参数取**极值**（如 min_ent=2.0、coh=10、indep=1.0、spe=2.0、mr=0.9、bind=0.5），
  其余锁 θ₀，单独观察：
  - 词数坍缩到多少（全滤阈值）；
  - 是否出现异常（负分/空表/崩溃）；
  - 极端值下哪类词最先牺牲（用 diff 看删词构成）。
- 目的：圈定**合法参数域**（后续差分搜索的硬边界），并找出"危险区"。

### 3.3 一阶差分敏感性 + 粗精两阶段（借鉴反向传播的边际贡献思想）

**思想**：不要求 loss 可微。把每个参数 θᵢ 的"梯度"定义为**单参数扰动的边际贡献**：

```
Δscore(θᵢ) = score(θᵢ 动一档/一步) − score(当前θ)
```

- Δscore > 0 → 该方向是改进方向；< 0 → 反方向。
- **连续参数**"动一步" = +step（粗跑大步，精跑小步）。
- **离散参数**"动一档" = 相邻取值（mean↔max、1→2→4→8、4→6→8→12、关↔开），
  与连续参数**同一套框架**，无需 32 组合嵌套枚举。

**两阶段（coarse-to-fine）**：

```
Phase A 粗跑：每参数大步长全空间扫一遍（档位 = 细扫的 1/4~1/5），
        只记录单调段 / 拐点 / 平台交界，标记"可疑区间"。
Phase B 精跑：只对可疑区间细化步长重扫（区间 = 粗峰值 ± 1~2 个粗步长），
        锁定精确阈值与边界。
```

> ⚠️ score 是分段常数（硬阈值阶跃），大步长可能跨过窄峰——精跑区间必须放宽到
> 「粗峰值 ± 1~2 个粗步长」，不能只精跑峰值那一格。

**坐标下降（一次动一维，优先动 |Δscore| 最大的）**：

```
1) 每轮对 7 连续 + 5 离散共 12 个参数，各测一次 Δscore（单侧扰动，非中心差分）；
2) 取 |Δscore| 最大的参数，沿改进方向走一步（连续走 stepᵢ，离散走一档）；
3) 收敛：一轮内所有 |Δscore| 的改进 < 评估分辨率(0.01) 或连续 3 轮无变化；
4) 随机重启：随机搜索 top5（见 3.4）作种子，各跑一遍取全局最优。
```

- 评估分辨率：score 最小步长 ≈ 1/37 ≈ 0.027，收敛判据不得低于此（否则永不触发）。
- 实现：`调参产物/tune_grad.py`。粗跑 ~5 档 × 12 参数 ≈ 60 评估；精跑只对可疑区间。
  连续阈值参数评估 ≈ gate 重跑（≈0）；仅 mr / len / no_punct / no_merge 需重 scan（0.25s/次）。

### 3.4 全局随机搜索（防局部最优 + 提供精跑/重启种子）

- 在合法参数域内**均匀随机采样** 50~100 个 θ（阈值在 log 或线性空间，**固定 seed** 保证复现），
  三套权重各评一遍，取每套 top5。
- 与差分结果交叉：随机 top5 作为 3.3 坐标下降的**重启种子**，也是粗跑"可疑区间"的候选锚点。
- 实现：`调参产物/random_search.py`。

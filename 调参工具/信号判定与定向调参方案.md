# 新一轮全量测试方案（v2，待批准）

> 目标：在证明（过滤 vs 救援不可兼得 + 分离带充要条件）和数据已知缺陷的基础上，
> 做一轮**更细化、更有针对性**的全量测试。不跑已判定无信息的档位，把全量预算
> 集中到能回答"下一步怎么调"的方向。
> **本轮全部档位用现有 cli / run_full_union 机制，不修改 grow3 任何代码。**

---

## 0. 设计原则（由证明直接推导）

1. **不跑过滤门**：role/asym 已判定混叠（min₍B∩T₎ ≤ max₍F∩G₎），其过滤档位 23 档全废，本轮彻底排除。
2. **预算集中到救援阈值联合区**：救援阈值是"多救真词 vs 少混碎片"的平衡，是唯一值得细扫的方向；之前只做了单维扫描，本轮做 **2D 联合网格**。
3. **零成本复用**：分离带判定、碎片混叠统计、词云视角全部用已有产物分析，不新增档位。
4. **评估对齐生产**：增加"词云 top200 视角"（用户已定：召回更重要，因为词云只显示窗口内）。

---

## 1. 六层测试设计

### 层 1：信号官方定位（分离带实测，0 档，纯分析）
用已有产物（`调参产物/fullrun/base`、`out/title_wordfreq.csv`、68 档中间产物）对每个信号
`ent / cohesion / role / asym / spe / rsr / indep` 算：

| 量 | 含义 |
|---|---|
| min₍B∩T₎(s) | 基线保留真词的最低信号值 |
| max₍F∩G₎(s) | 被滤碎片的最低…（最高信号值） |
| 分离带宽 | min − max；>0=可过滤，≤0=混叠 |

**产出**：信号定位表 + 与 68 档实测结论的一致性核对（role/asym 应判混叠、ent/coh 应判分离）。
**作用**：把证明落地成"每个信号的官方位置"，也作为未来新信号（U2 变体等）的判定模板。

### 层 2：救援阈值 2D 联合网格（15 档，本轮核心）
之前只跑了一维（role 或 asym 单独）和少量组合，本轮在**最优区间内做 2D 交叉**：

```
asym_rescue ∈ {1.5, 1.75, 2.0, 2.25, 2.5}
role_rescue ∈ {0.6, 0.7, 0.8}
基线：ent0.5 + coh1.5 + indep0.05 + role/asym enabled
```

**产出**：2D 指标热力表 + 帕累托前沿（真词召回 vs 碎片混入的 trade-off 曲线）。
**要回答的问题**：
- 2D 最优组合是否优于 F3 单点（role0.7+asym2.0）？
- 曲面是平滑还是有窄峰？最优在边界上吗（决定要不要扩范围）？

### 层 3：碎片混叠定量（0 档，纯分析）
用 `out/title_wordfreq.csv`（F3 产物，含 role/asym 列）：
- F3 新增 264 词中，role>0.7 / asym>2.5 / 两者都过的**碎片数量**
- 真词与碎片在 role、asym 两轴上的分布重叠度（分位数相交情况）
**产出**：一份定量报告——"结构性代价"到底有多大、有多少碎片与真词数学上不可分。
**作用**：把这个代价从"口头结论"变成"定稿数字"，避免未来反复试探"能不能调掉"。

### 层 4：阈值敏感词稳定性（2 档，U2 vs 不动点）
已知：U2 与不动点在 role 值 ≈0.5 的阈值线上横跳（差异词 133 个，含世界/系统/凡人等真词）。
本轮在 **F3 救援场景**下重测：
- 档①：F3 用 role_max_depth=1（U2）
- 档②：F3 用 role_max_depth=-1（不动点）
**产出**：两词表 diff + 差异词是否含真词/是否影响 000/keep 指标。
**作用**：定案默认 `role_max_depth`（若 U2 与 fix 在救援场景下无差异 → U2 转正，省计算）。

### 层 5：welded 真词确认（0 档，纯分析）
从候选池/产物中确认"补集罕见字"真词（天道、历史类）的 role/asym 值。
**产出**：确认这些词纯结构信号救不回 → 记录为已知结构性边界。
**作用**：为"下一步改进方向"划清界限（这类词要靠语义/字典，不在纯结构路线内）。

### 层 6：词云 top200 视角（0 档，纯分析）
对 base、F3、层 2 最优 三个词表，按 count 排序模拟词云 top200：
- top200 内 000 真词数 / 碎片数
**产出**：展示层对比表。
**作用**：对齐用户"召回更重要、词云只显示窗口"的判断——预期真词仍进不了 top200（低频），
为"排序载体/精选区"实验提供数据支撑（但**排序实验本身不在本轮**）。

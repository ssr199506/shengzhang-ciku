## 1. 各维精确曲线（参数 → 词数 / 碎片命中）

### coh（越小词越多，碎片越多）
```
coh1.0=5367 碎10   coh1.25=5255 碎10   coh1.5=5149 碎8   coh1.75=5012 碎8
coh2.0=4905 碎8    coh2.25=4764 碎8    coh2.75=4468 碎7   coh3.0=4330 碎7
coh3.5=3988 碎6    coh4.0=3654 碎5
```
→ **严格单调递减**，0.25 档距下无回升、无窄峰。1.5 基准处在平滑段，不是特殊峰。

### indep（越小词越多）
```
indep0=5156 碎9   indep0.02=5155 碎8   indep0.03=5153 碎8   indep0.04=5151 碎8
indep0.05=5149 碎8   indep0.06=5146 碎8   indep0.08=5134 碎8   indep0.1=5127 碎8

```
→ **严格单调递减**，0.05 基准附近平坦（5153~5149 几乎不变）。无窄峰。

### ent（越小词越多）
```
ent0.3=5172 碎9   ent0.35=5171 碎9   ent0.45=5158 碎8   ent0.5=5149 碎8
```

### mr（越大词越多，召回旋钮）
```
mr0.1=5087 碎8   mr0.15=5106 碎8   mr0.25=5149 碎8   mr0.35=5385 碎8
mr0.4=5385 碎8   mr0.5=5393 碎9   mr0.65=6109 碎9   mr0.7=6143 碎9
mr0.85=6153 碎9  mr0.95=6156 碎9
```
→ **单调递增**，但存在真实非线性台阶：mr 0.5→0.65 之间词数从 5393 跳到 6109（+716）。
   0.35~0.4 持平（可能量化边界），0.65 以上趋平台（~6150）。**这是召回旋钮最敏感区间**。

### spe 救援（关键新发现：开关式效应）
```
spe0(基准)=5149 碎8     spe0.2=5248 碎16    spe0.4=5246 碎16
spe0.6=5240 碎16        spe0.8=5232 碎16    spe1.0=5173 碎13
spe1.5=5159 碎9         spe2.0=5149 碎8
```
→ **不是「越多越糟」的简单单调，而是「开了就糟、关了才好」的开关式效应**：
   - 只要开了救援门（0.2~0.8 任何值），碎片立刻全中 **16/16**，词数还多 ~100（捞回的词里混着碎片）；
   - 关掉（=0）或开到极大（=2.0，超过阈值不触发救援）才恢复正常 8/16。
   → **SPE 救援门必须关闭（spe=0）**，与粗跑结论一致，且现在更精确。

## 3. 结论：细化后和粗跑比，有什么不同？

**主结论完全不变**：基准 5149 维持最优，spe 必须关，碎片是系统盲区。

**但细化让结论更扎实、更精确**：
1. **排除了"粗跑漏窄峰"的担忧**：coh/indep/ent 三旋钮在 0.25 档距下**严格单调**，没有隐藏的峰被大步长跨过——粗跑的"5149 是局部最优"判断稳健。
2. **精确刻画 SPE 救援的开关式危害**：不是渐进恶化，而是"开门即全中碎片"的二元效应，关掉是唯一正解。
3. **定位 mr 召回台阶**：0.5→0.65 是召回旋钮最敏感区间（词数跳 +716），想大幅加词就开到 mr≥0.65。
4. **共识交集收窄到 3398**：高质量核心更精炼，但碎片仍漏，黑名单仍是必要补充。

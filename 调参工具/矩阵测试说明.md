# 纯结构信号测试矩阵 · 执行说明

> 针对 `role-asym` 分支新增的两个纯结构信号（**role** 偏序图角色迭代、**asym** 条件熵不对称性）
> 与原有信号的关系验证。机械运行、自动出结果，无需人工干预。
> 配套脚本：`run_matrix.py`（本目录）；评估引擎：`tune_engine.py`（已扩展 role/asym 支持）。

## 一、一句话背景

两个新信号与原有信号的关系假设（决定后续转正/退役决策）：

| 关系 | 信号对 | 待验证 |
|---|---|---|
| 升级取代 | role → SPE/RSR | role 的救援质量 ≥ SPE？ |
| 功能正交 | role ↔ 复合熵 | 双过滤是否互补不误伤 |
| 2D 决策面 | role × 凝固度 | 「内紧∧外主」能否滤虚词前缀短语 |
| 逆向互补 | asym ↔ 复合熵 | ent 滤 → asym 救的互补链 |
| 特化子集 | asym ⊂ role | asym 捞回 + role 净化能否去噪 |
| 功能重叠 | asym ↔ SPE | 两救援源冗余还是互补 |

## 二、前置条件

- 在 **role-asym 分支**（`git checkout role-asym`），因为 grow3 含 role/asym 信号。
- 项目根有 `corpus.csv`（8887 本）与 `grow3/` 包。
- 环境变量（本机沙箱 safe-delete 问题）：跑前加
  `CODEBUDDY_SESSION_ID= CLAUDE_SESSION_ID=` 前缀。

## 三、一键运行

```bash
cd 调参工具

```

## 四、四层矩阵定义

### 层 1 · 单信号标定（12 格）
在**纯熵基线**（coh/indep/spe/rsr 全关）上逐个标定新信号：
- `role滤@0.3/0.5/0.7/0.9`：role 当过滤门，每档滤掉什么/误伤什么
- `asym救@1.0/1.5/2.0/2.5`：asym 当救援门，每档捞回什么/混入什么
- `spe救对照@0.5/0.8/1.0`：现有 SPE 救援对照

### 层 2 · 两两联合（31 格）
| 组 | 组合 | 回答 |
|---|---|---|
| 互补链 | ent∈{0.4,0.5,0.6} × asym∈{1.5,2,2.5} | ent 越严 asym 是否救得越多/越脏 |
| 2D 决策面 | role∈{0.3,0.5,0.7} × coh∈{1.0,1.5} | 在三国（role高×coh低）滤不滤、首富（双高）伤不伤 |
| 正交双滤 | ent×{0.4,0.5,0.6} × role∈{0.3,0.5,0.7} | 双过滤比单 ent 多滤什么 |
| 救援+净化 | asym=2.0 × min_role∈{0.3,0.5} | 救援集里噪声（我终/真没）与真词（首富）在 role 轴上切不切得开 |
| 内外对称 | asym=2.0 × coh∈{1.0,1.5} | 救援集用凝固度净化 vs role 净化 |
| 取代对比 | role救@0.7/0.9 vs spe救@0.8 | 谁召回高、谁噪声少 |

### 层 3 · 完整管道（5 格）
- **E** `ent-only`（基准）
- **A** `ent→asym救→role净化`（min_role 兼过滤门与救援净化门槛）
- **B** `ent→spe救→role净化`（同形态换救援源）
- **C** `ent→role救`（role 独立救援）
- **D** `ent+coh1.0+role滤+asym救`（完整链）

### 层 4 · 正交表（16 格）
`ent∈{0.4,0.5} × coh∈{0,1.0} × role∈{0,0.5} × asym∈{0,2.0}` 全组合，
看主效应与交互（谁是旋钮、谁是开关）。

## 五、输出产物

```
matrix/
  layer1.csv ... layer4.csv   # 每格一行：n_kept / keep / filt / 000 / frag / coll / score_A/B/C / kept_targets
  report.md                   # 自动汇总：各层最佳格 + 关键词存活 + 关键对比表
```

- `kept_targets` 列：`首富/庆余年/康熙/在三国/家的/我终/真没/无限之` 等 19 个关键词
  在该配置下的存活情况（`+` 连接），直观看出"决策面是否滤对、净化是否去噪"。

## 六、评估口径（沿用 tune_engine）

- `keep`：应留词命中 / 37（金标准 KEEP，越高越好）
- `filt`：应滤词残留 / 25（越低越好）
- `000`：000 层疑似真词捞回 / 15（庆余年/首富/康熙…，越高越好）
- `frag`：已知碎片残留 / 18（越低越好）
- `coll`：高频误伤数（count≥5 且非金标准集，越低越好）
- `score_A/B/C`：三套权重加权分（A 均衡 / B 召回重 / C 召回极重）

## 七、怎么读结果（关键判断点）

1. **层 1 谁捞 000 层**：`asym救@2.0` 的 000 数 vs `spe救对照` 的 000 数——若 asym 明显更高且 filt 可控，asym 有取代 spe 的资格。
2. **层 2 决策面**：`role×coh` 格里看 `kept_targets`——"在三国/家的"消失但"首富/庆余年"还在，即「内紧∧外主」成立。
3. **层 2 净化**：`asym2.0净role0.5` 比 `asym救@2.0` 的 frag 是否下降、000 是否保留——验证「asym 捞回 + role 净化」。
4. **层 3 管道**：A vs B（asym 救援源 vs spe 救援源）同净化下谁更好；D 是否最优。
5. **层 4 主效应**：score 随哪个因子变化最大（旋钮排序）。

## 八、新参数参考表

| 参数 | 类型 | 语义 |
|---|---|---|
| `role_enabled` | bool | 计算 role 列 |
| `role_max_depth` | int | 1=U2，N=迭代 N 帧，-1=不动点 |
| `role_alpha` | float | 迭代阻尼（默认 0.85） |
| `min_role` | float | role 过滤门 + asym 救援净化门槛；<=0 关 |
| `role_rescue` | float | 从被滤集捞回 role>=thresh；<=0 关 |
| `asym_enabled` | bool | 计算 asym 列 |
| `asym_rescue` | float | 救援阈值（大正=被虚词修饰的主干）；<=0 关 |

## 九、注意

- 层 1/2 用**纯熵基线**（关闭 coh/indep/spe/rsr），是为了隔离 role/asym 效应；
  层 3 的 D 才是接近生产形态的完整配置。
- 角色（role）不动点计算每次 ~1s，全矩阵约 2 分钟；`--fast` 用 U2 可压到 30 秒内
  （U2 与不动点的差异本身也可作为"深度增益"的观察点）。

## 十、全量交并流程（run_full_union.py）

run_matrix.py 用验收集打分（快但依赖人工金标准集）；**run_full_union.py 走全量实测**：
每一档参数真实跑一遍完整 cli，产出一版全量 `title_wordfreq.csv`，再与**过去版本 base
（调参产物/fullrun/base，5149 词）逐档求交并**，统计每档相对 base 新增/删除的词里，
000 层真词与碎片各占多少——完全不受评估集主观影响。

```bash
python run_full_union.py               # 全 6 层 53 档（~40 秒）
python run_full_union.py --layer A     # 只跑单层 A~F
python run_full_union.py --skip-run    # 已跑过的档不重跑，只重做交并汇总
```

**档位网格（步长已细化）**：

| 层 | 旋钮 | 取值 | 档数 |
|---|---|---|---|
| A | role 过滤门 min_role | 0.25~0.85 步长 0.05 | 13 |
| B | role 救援门 role_rescue | 0.45~0.95 步长 0.05 | 11 |
| C | asym 救援门 asym_rescue | 0.5~3.0 步长 0.25 | 11 |
| D | role 迭代深度 max_depth | 1/2/3/4/-1（固定 min_role=0.5） | 5 |
| E | asym救(2.0)×role净化 min_role | 0~0.6 七档 | 8 |
| F | 完整管道 | F1~F5（ent+coh 基础上组合） | 5 |

**评估口径（交并，锚=过去 base）**：
- `+000真 / -000真`：相对 base 新增/删除里命中 000 层 15 词的个数（加多删少为好）
- `+碎片 / -碎片`：新增/删除里命中句法碎片（base 残留 4 个）
- `keep / filt`：37 保留词命中 / 25 应滤词残留
- `net = 000真词净增 + 碎片净减`

**产物**：`调参产物/fullrun_role/<档名>/title_wordfreq.csv` + `union_summary.csv`
+ `交并报告.md`（自动汇总 + 结论）。

**关键结论（2026-08-14 全量实测）**：
- asym 救援门 `asym_rescue=2.0` 是主力：000 层真词 0/15 → 13/15，keep 无损，碎片仅 +3；
- role **只能救援/净化、不能过滤**（过滤门 keep 35→14 直线崩，000 零回收）；
- 推荐 `role_rescue=0.7 + asym_rescue=2.0`（F3）：13/15 真词 + keep 全保 + 碎片 +3；
- role 迭代深度对结果几乎无影响，U2 即可，无需不动点成本。

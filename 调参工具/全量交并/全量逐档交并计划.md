# 全量逐档交并调参计划（给免费模型执行的保姆级版）

> 目标读者：只看得懂 `python xxx.py` 的免费 AI 或人，不需要懂算法。
> 本计划替代之前的"评估引擎打分"法：**每一档参数都真实跑一遍全量数据、产出一版完整词表 CSV，
> 再把各版本词表做交并汇总**——这是最直接、最难出错、也不依赖任何评估集的方法。
> 工作目录：`项目根目录`（沙箱，产物不许外溢）。

---

## 〇、这份计划是干什么的

一句话：**把参数换 13 档，每档跑全量数据出一版词表，13 版词表做交并，汇总成一份报告。**

- 上一版调参用了"评估引擎"：只拿 95 个金标准词打分，快但没出全量词表，也没算各版本的交并。
- 本计划是**全量实测**：每档都真实产出一版词表（`title_wordfreq.csv`，5149 词量级），然后算
  「哪些词所有档都保留（共识交集）」「哪些词某档独有（差异）」「换档增删了谁」，最后汇总成报告。
- 这样调参结论完全建立在真实词表上，不受任何评估集主观选择影响。

## 二、认识基准命令（先会跑这一条）

下面这条命令是"基准版"（当前推荐配置，预期产出 **5149 词**）：

```bash
python -m grow3.cli corpus.csv --title-col 2 --intro-col -1 \
  --ent-merge-ratio 0.25 --min-ent 0.5 --cohesion 1.5 --indep 0.05 \
  --no-cloud --out 调参产物/fullrun/base
```

命令拆解（每个参数对应一个词，别记混）：

| 参数 | 值 | 含义 |
|---|---|---|
| `--ent-merge-ratio` | 0.25 | 熵合并比例（候选池大小旋钮） |
| `--min-ent` | 0.5 | 复合熵门槛 |
| `--cohesion` | 1.5 | 凝固度门槛 |
| `--indep` | 0.05 | 独立频次占比门槛 |
| `--no-cloud` | — | 跳过词云渲染，只产词表（加速） |
| `--out 调参产物/fullrun/base` | — | 产出目录（**必须是沙箱内**） |

跑完检查 `调参产物/fullrun/base/title_wordfreq.csv` 存在，且是 5149 行（含表头，实际词 5148+ 表头 1 行）。

> ⚠️ 参数名注意：是 `--cohesion` 不是 `--min-cohesion`；是 `--indep` 不是 `--min-indep`。
> 每条命令把整行一次跑完，`\` 是换行符（bash），也可写成一整行不带 `\`。

## 三、档位设计（13 版，控制变量法）

**规则：每一档只动一个参数，其余 4 个参数锁死为基准值**（me0.5 / mr0.25 / coh1.5 / indep0.05 / spe0）。

| 编号 | 档名 | 动的参数 | 参数值 | 其余参数 |
|---|---|---|---|---|
| 0 | base | （都不动） | — | 基准 |
| 1 | coh1.0 | --cohesion | 1.0 | 锁基准 |
| 2 | coh2.0 | --cohesion | 2.0 | 锁基准 |
| 3 | coh3.5 | --cohesion | 3.5 | 锁基准 |
| 4 | indep0 | --indep | 0.0 | 锁基准 |
| 5 | indep0.03 | --indep | 0.03 | 锁基准 |
| 6 | indep0.1 | --indep | 0.1 | 锁基准 |
| 7 | ent0.3 | --min-ent | 0.3 | 锁基准 |
| 8 | ent0.7 | --min-ent | 0.7 | 锁基准 |
| 9 | mr0.1 | --ent-merge-ratio | 0.1 | 锁基准 |
| 10 | mr0.5 | --ent-merge-ratio | 0.5 | 锁基准 |
| 11 | mr0.85 | --ent-merge-ratio | 0.85 | 锁基准 |
| 12 | spe0.8 | --spe-rescue | 0.8 | 锁基准 |

> 为什么这样设计？控制变量法保证"换档的差异只来自那一个参数"，交并分析才有意义。
> 想加密档位（比如 coh 加一档 1.5→2.5、mr 加 0.65）可以照抄规则自己加，但先跑完这 13 版。

每条命令 = 第 0 条基准命令，把 `--out` 目录和对应参数值换掉。以 3 条为例：

```bash
# 基准（编号 0）

# 编号 1：coh 改 1.0

# 编号 12：开 SPE 救援 0.8
python -m grow3.cli corpus.csv --title-col 2 --intro-col -1 --ent-merge-ratio 0.25 --min-ent 0.5 --cohesion 1.5 --indep 0.05 --spe-rescue 0.8 --no-cloud --out 调参产物/fullrun/spe0.8
```

## 五、写交并统计脚本（核心，保存下面的代码直接跑）

在沙箱内新建文件 `调参产物/fullrun/union.py`，内容**原样复制**下面的代码（不需要懂，直接保存）：

```python
# -*- coding: utf-8 -*-
# 全量逐档交并统计：读 13 版词表 -> 算交集/并集/增删/碎片 -> 输出汇总
import csv, os, sys
from collections import Counter

ROOT = os.path.dirname(os.path.abspath(__file__))
DIRS = ["base","coh1.0","coh2.0","coh3.5","indep0","indep0.03","indep0.1",
        "ent0.3","ent0.7","mr0.1","mr0.5","mr0.85","spe0.8"]

def load_words(label):
    p = os.path.join(ROOT, label, "title_wordfreq.csv")
    words = {}
    with open(p, encoding="utf-8-sig", newline="") as f:
        for i, r in enumerate(csv.reader(f)):
            if i == 0 or not r:          # 跳过表头/空行
                continue
            words[r[0]] = int(r[1])       # 词 -> 频次
    return words

allw = {lab: load_words(lab) for lab in DIRS}
base_w = set(allw["base"])

# 1) 每版词数
print("== 各档词数 ==")
for lab in DIRS:
    print("  %-10s %5d 词" % (lab, len(allw[lab])))

# 2) 共识交集（13 版全部保留）= 最稳定的词
cons = set.intersection(*(set(v) for v in allw.values()))
print("== 交并 ==")
print("  13 版共识交集(全部保留): %d 词" % len(cons))

# 3) 每档相对基准的增/删
print("== 相对基准(base)的增删 ==")
for lab in DIRS[1:]:
    s = set(allw[lab])
    add = s - base_w
    rem = base_w - s
    print("  %-10s +%4d  -%4d" % (lab, len(add), len(rem)))

# 4) 碎片命中（人工标注的句法碎片，检查哪些档把它们放进来/滤掉）
FRAG = ["我的","这个","什么","成了","我是","我在","人在","重生之",
        "我只","联盟之","罗之","之我","世界之","是我","的我","之神"]
print("== 碎片命中（越少越好）==")
for lab in DIRS:
    s = set(allw[lab])
    hit = [w for w in FRAG if w in s]
    print("  %-10s %2d/16 %s" % (lab, len(hit), " ".join(hit)))

# 5) 导出汇总 CSV
with open(os.path.join(ROOT, "union_summary.csv"), "w", newline="", encoding="utf-8-sig") as f:
    w = csv.writer(f)
    w.writerow(["档名", "词数", "相对基准新增", "相对基准删除", "碎片命中数"])
    for lab in DIRS:
        s = set(allw[lab])
        w.writerow([lab, len(s), len(s - base_w), len(base_w - s),
                    len([x for x in FRAG if x in s])])
print("== 已输出 union_summary.csv ==")
```

### 运行它

```bash
python 调参产物/fullrun/union.py
```

### 预期输出（判断跑对没）

```
== 各档词数 ==
  base        5149 词
  coh1.0      ??? 词    # 应比 base 多（门槛低，放进来更多）
  coh2.0      ??? 词    # 应比 base 少
  coh3.5      ??? 词    # 应更少
  ...
  mr0.85      ??? 词    # 应比 base 多（候选池大）
  spe0.8      ??? 词    # 应比 base 多（救援捞回词）
```

趋势判断规则（三条，符合就说明跑对了）：
1. `coh` 越大词越少、`indep` 越大词越少、`min-ent` 越大词越少 → 这三个是"收紧旋钮"；
2. `ent-merge-ratio` 越大词越多 → 这是"放开旋钮"；
3. `spe0.8` 词数应大于 base（救援门捞回一批词），且碎片命中数**不应**小于 base（历史上 SPE 会捞回碎片）——如果 spe0.8 的碎片数明显变少，说明跑错了，停下来检查。

## 六、汇总成报告

跑完 `union.py` 后，在 `调参产物/fullrun/交并汇总报告.md` 里写（**把上面的输出照抄进去**）：

```markdown
# 全量逐档交并汇总报告

## 1. 各档词数表（抄 union.py 输出）
| 档名 | 词数 | 相对 base 增 | 相对 base 删 | 碎片命中 |
|---|---|---|---|---|

## 2. 共识交集
- N 个词在全部 13 档都保留 —— 这些是"怎么调都不掉"的最稳词，质量最高。

## 3. 关键差异
- 哪一档把碎片全部滤掉（碎片命中=0 的档，若有）；
- 哪一档漏进碎片最多；
- spe0.8 相对 base 多放了哪些词（列出具体词，人工判断值不值得）。

## 4. 结论
- 综合"词数合适 + 碎片最少"选 1~2 个候选配置；
- 说明和基准 base 的取舍（比如"coh2.0 碎片 0 但少 N 词"）。
```

## 七、陷阱与注意事项（免费模型必读）

| 情况 | 处理 |
|---|---|
| 输出中文乱码 | 命令前加 `PYTHONIOENCODING=utf-8`，或不管（CSV 不受影响） |
| `--out` 目录名必须与档名一致 | 交并脚本按目录名读，不一致会找不到文件 |
| 词数跟预期差很远 | 检查参数名是否拼错（--cohesion/--indep/--min-ent 别写反） |
| 产物外溢 | 所有 `--out` 必须写成 `调参产物/fullrun/xxx`；发现别处有生成文件就是跑错了 |
| 忘记记录 | 每跑完一档立刻在 `运行记录.md` 记词数，别攒到最后 |
| 想加档位 | 照 §三 规则加（只动一个参数），并同步加进 union.py 的 DIRS 列表 |
| 免费模型看不懂 | 它只需要会复制命令和复制代码，不需要懂算法 |

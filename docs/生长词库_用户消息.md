**核心**：PUNCT 在不同词上扮演不同角色，应该让**每侧根据 PUNCT 占比自主决定**是否空化。
**具体做法**：
- 在计算 `l_non` / `r_non` 时，引入局部阈值（如 0.85）：
- 如果某一侧的 `PUNCT / (PUNCT + 汉字) > 0.85`，该侧 PUNCT 视为“准空”
- 否则，PUNCT 正常计入“不空”
**预期效果**：
- **什么鬼**：右侧 PUNCT 95.5% > 0.85 → PUNCT 空化 → 右侧几乎无有效邻居 → 触发合并 → 高熵 → **保留**
- **一人之下**：右侧 PUNCT 81% < 0.85 → PUNCT 计入 → 右不空大 → 左不空小 → 触发合并 → **保留**
- **我能**：左侧 PUNCT 约30% + 空68% + 汉字1% → PUNCT 占比 <85% → PUNCT 计入 → 左不空大 → 两侧都有数据 → `min(左熵0, 右熵高)` → 0 → **过滤**
**这个方向的风险**：如果 PUNCT 占比正好在阈值附近，可能产生边缘抖动。但可以容忍，因为它是单侧决策，不影响整体。
